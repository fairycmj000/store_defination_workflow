> 生成日期：2026-10-15
> 权威来源：
> - `clients/mars/systems/business-middle-platform/store-center/ontology/object-types/customer-hq.md`（对象类型摘要）

## 0. 对象定位

| 项 | 值 |
|---|---|
| 对象类型 | `CityHeadquarters`（总部客户：客户系列 / 全国总部 / 城市总部） |
| backing 表 | `city_headquarters`（库 `customer_manage`，**12,249** 行；另有 `customer_poplar.city_headquarters` 及 `_prod`/`_p`/快照） |
| 主键 | `code`（业务键，格式 `Cityhq + 随机数字`，自动生成不可编辑，BR-SD-721） |
| 层级表达 | 三级由**一个对象类型 + 层级值 + 自链接**表达（非三个类型） |
| writeback owner | 公海门店门户 / 供销中心（两套入口，BR-SD-701） |
| 关联 | `customer-city-hq`：`Customer ↔ CityHeadquarters`（N:1，经 `city_headquarters.customer_basic_code`）；`Store → CustomerHq`（门店归属城市总部） |

## 3. 城市总部维护页字段（BR-SD-721）

维护页字段全集：**客户编码 / 客户名称 / 客户属性 / 上级编码 / 渠道 / KA 类型 / 玛氏销售地理区域 / 供货品类 / 各品类供货商 / 各渠道是否连锁 / 指定客户类型 / 零食客户系列**。

> 其中「客户属性」对应 `cityhq_type`（客户系列/全国总部/城市总部）；「各品类供货商」对应 hqSupply 供货关系（5 品类）。

## 4. 关键判定函数（派生字段来源）

| 函数 | 输出 | 说明 |
|---|---|---|
| `f-hq-chain-flag` | `is_chain`（是否连锁，8 维） | 全国总部与城市总部是否连锁；按渠道、阈值 **≥10 家** |
| `f-hq-rtm-calc` | `rtm_channel`（城市总部 RTM） | 现代/传统/零食按 KA；特殊/新模式按是否连锁；批发=WS；线上=O2O 前置仓 |

## 5. 继承与校验规则（BR-SD 摘录）

| 规则 | 要点 |
|---|---|
| BR-SD-112 | 城市总部侧 RTM 判定（现代/传统/零食按 KA 类型） |
| BR-SD-307 | 零食渠道店型：全国总部「指定客户类型」第一层判据，不满足才下沉城市总部「是否连锁」 |
| BR-SD-314/315 | 门店侧 RTM 判定：Seeding/Special 按城市总部是否连锁；NM 2026 起固定 New Model 不再按是否连锁 |
| BR-SD-329 | 是否连锁初始化：实名制全国总部按渠道计算（≥10 家）；城市总部实名制继承上级、非实名制按所维护渠道计算 |
| BR-SD-909 | 城市总部渠道维护限制逐版收紧：2025 限 WS/EOM/Online 非 O2O 前置仓；2026 仅提 WS 与 EOM |
| BR-SD-910 | SIT「拉链数据导致同一客户多条记录」已修复 |
| BR-SD-712 | 仍有带店不允许关闭 |
| BR-SD-720/303a | 「是否承包制经销商虚拟门店」与人店关系/RTM SIP 细分判据同源 |

## 6. 完整度与待核（诚实标注）

| 项 | 状态 |
|---|---|
| `city_headquarters` 全表列清单 | **未转录**——本表字段来自对象类型摘要 + 判定规则 + ontology 关联，非逐列点算 |
| 主键列 `code` vs `customer_basic_code` | **待核**：对象类型写「主键 customerCode 对应列 customer_basic_code」，但 ontology 写「主键 `code`、经 `customer_basic_code` 关联 Customer」——两者是同一列还是两列，需按 `city_headquarters` 表结构确认 |
| `designatedCustomerType` / `snackCustomerSeries` / `hqSupply` 物理列名 | **待补**：值类型已知，物理列名未在知识库落列 |
| 各渠道 `is_chain` 的 8 个维度物理列 | **待补**：只知 `is_chain`（按渠道）一个列，8 维（MT-TT/Snacking/NM/WS/Online/Bulk/Seeding/Special）是否拆列未知 |
