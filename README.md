# store_defination_workflow

门店定义（Store Definition）个人工作流仓库：记录门店定义领域的知识梳理、字段主数据、血缘关系、影响评估与自动化工具等**在途 / 产出材料**。

> 本仓库**不包含** knowledge-space（独立仓库 `inkstone-lab/knowledge-space`）。

## 目录与资产性质

| 路径 | 说明 | 性质 |
|---|---|---|
| `个人行动指南.md` | 行动清单 / 路线图（分业务领域） | **个人产出物 · 暂时非公共资产** |
| `门店定义知识库探究-避坑指南.md` | 探究踩坑记录（KB-001/002…） | **个人产出物 · 暂时非公共资产** |
| `数据资产\` | 门店 / 城市总部主数据字段清单等 | 数据资产 |
| `检索输出\` | 检索与能力测试报告 | 过程输出 |
| `自动化工具\` | 自动化工具设计 / POC | **个人产出物 · 暂时非公共资产** |
| `业务知识全景\` | 字段血缘图、应用端联动全景 | **个人产出物 · 暂时非公共资产** |
| `业务中台架构\` | 业务中台资产层次梳理 | **个人产出物 · 暂时非公共资产** |
